# 📝 Changelog - API Implementation

## [1.0.0] - 2026-01-06

### 🎉 Добавлено

#### API Контроллеры
- **`app/controllers/api/v1/base_controller.rb`**
  - Базовый контроллер для всех API эндпоинтов
  - Token-based аутентификация через заголовок Authorization
  - Централизованная обработка ошибок (404, 422, 400)
  - Метод `authenticate_api_user!` для проверки токена
  - Метод `current_api_user` для доступа к текущему пользователю

- **`app/controllers/api/v1/auth_controller.rb`**
  - `POST /api/v1/auth/register` - Регистрация нового пользователя
  - `POST /api/v1/auth/login` - Аутентификация пользователя
  - `POST /api/v1/auth/logout` - Выход (инвалидация токена)
  - `GET /api/v1/auth/me` - Получение информации о текущем пользователе
  - Автоматическая генерация и возврат API токена

- **`app/controllers/api/v1/posts_controller.rb`**
  - `GET /api/v1/posts` - Список постов с пагинацией
  - `GET /api/v1/posts/:id` - Получение одного поста с комментариями
  - `POST /api/v1/posts` - Создание поста (требует аутентификации)
  - `PATCH /api/v1/posts/:id` - Обновление поста (только автор)
  - `DELETE /api/v1/posts/:id` - Удаление поста (только автор)
  - Поддержка поиска по заголовку и содержимому
  - Фильтрация по пользователю
  - Пагинация (page, per_page, максимум 100 постов)
  - Поддержка загрузки изображений
  - JSON сериализация с вложенными данными (user, images, comments)

### 🐛 Известные ограничения

1. **Токены не имеют срока действия** - токены действуют бессрочно до явного выхода
2. **Нет rate limiting** - отсутствует ограничение на количество запросов
3. **Базовая аутентификация** - только токены, нет OAuth/JWT
4. **Нет версионирования токенов** - при выходе токен просто регенерируется
5. **Простая пагинация** - нет cursor-based пагинации для больших датасетов

## Структура API

```
/api/v1
├── /auth
│   ├── POST   /register     # Регистрация
│   ├── POST   /login         # Вход
│   ├── POST   /logout        # Выход
│   └── GET    /me            # Текущий пользователь
└── /posts
    ├── GET    /              # Список постов
    ├── GET    /:id           # Один пост
    ├── POST   /              # Создать пост
    ├── PATCH  /:id           # Обновить пост
    └── DELETE /:id           # Удалить пост
```
